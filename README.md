# krishnapermi.net

Personal blog of Krishna. Static site built with [Eleventy](https://www.11ty.dev/), deployed on Cloudflare Pages, edited via [Pages CMS](https://pagescms.org/).

- Posts live in `src/posts/` as markdown with frontmatter (title, date, categories).
- Design lives in `src/assets/style.css` and `src/_includes/`.
- Every push to `main` auto-deploys.

Local preview:

    npm install
    npm run serve
